# How to build an Adapter

MirrorPulse Adapter SDK provides the public Worker API, wire protocol specification, and conformance tools for MirrorPulse Adapters.

- Start with the [Adapter template](https://github.com/mirrorpulse/adapter-template).
- Read the [Worker protocol](spec/worker-v2.md) for package and wire contracts.
- Use the sample Worker and conformance tool to validate an implementation.

The 1.0 development baseline targets one declared root per Adapter deployment.
